# Veilbound 0.1.59 validation

0.1.59 gives the lower Veilforged armor tiers distinct active identities instead of relying only on passive mitigation.

- Full Phaseweave converts ordinary fall impact into Core DE: 250 DE inside the owner Domain, 500 DE elsewhere.
- Full Causal armor can reject a lethal ordinary post-mitigation hit for 50,000 DE, then enters a 600-tick (30 second) runtime cooldown.
- Damage sources tagged to bypass invulnerability are intentionally excluded from both special defenses.
- Existing Sovereign Domain flight and remote Core administration remain unchanged.
- Both activations emit lightweight vanilla particles and action-bar feedback.

Validation requires Java 25 compilation, packaged class/resource audits, and exact-JAR NeoForge 26.2.0.75 dedicated-server startup.
